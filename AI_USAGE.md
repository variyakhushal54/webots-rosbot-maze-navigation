# AI Usage

This file describes how AI tools were used in this project, so readers can see what was generated with assistance and what was written and tested by the team.

## During the project (from the group's technical report, section 17)

- **ChatGPT** — used for code debugging and code optimisation: understanding error messages, comparing possible fixes, and improving the readability of the controller code.
- **Perplexity** — used for research and for understanding concepts such as mapping, path planning, robot navigation and controller design.

The team states that final implementation decisions, integration, testing, report structure and submitted results were made and checked by the project group.

## Preparing this repository

- **Claude (Anthropic)** — used to organise the files into this repository layout and to draft this README and the AI usage notes. The technical content in the README is taken from the group's report and the controllers' own documentation. The controller code itself was not rewritten for this repository.

## Scope

AI tools supported debugging, research and documentation. Algorithm design, controller integration, simulation testing and the recorded results are the work of the project team.
